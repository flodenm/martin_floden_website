## Steady-state output per worker with population growth

In the frame **“Steady state with population growth”**, equation `eqyss` omits a factor involving total factor productivity.

The archived slide states:

`y* = (sA / (delta + n))^(alpha / (1 - alpha))`.

Given

`k* = (sA / (delta + n))^(1 / (1 - alpha))`

and `y = A k^alpha`, the corrected expression is:

`y* = A^(1 / (1 - alpha)) (s / (delta + n))^(alpha / (1 - alpha))`.

Equivalently:

`y* = A (sA / (delta + n))^(alpha / (1 - alpha))`.

Use the corrected expression in explanations and calculations. Do not silently attribute it to the original slide: mention that the Fall 2025 slide contains a typographical error.
