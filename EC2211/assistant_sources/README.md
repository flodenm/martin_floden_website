# EC2211 course-assistant sources

This directory contains machine-readable course material for the EC2211 course assistant.

## Version policy

- `Fall_2026` is the current and authoritative course edition when material exists there.
- `Fall_2025` is archival reference material. An answer based only on this directory must say so explicitly and warn that details may have changed.
- Never combine notation, deadlines, assessment rules, or exercises from different course editions without clearly identifying the edition of each source.
- Cite the course edition, document name, and slide or section title whenever possible.

## Content policy

- Lecture-source files preserve text, equations, and document structure from Overleaf.
- Companion `figure_notes` files describe the pedagogical content of figures that are not stored here.
- Textbook figures, photographs, exam material, and solution material are excluded unless the course coordinator explicitly approves them.
- Administrative information in older lecture notes (for example Athena instructions and old deadlines) is historical, not current guidance.

## Included Fall 2025 material

- Lecture 2: Economic Growth and the Solow Model, with figure notes.
- Lecture 3: More on Growth Theory, with figure notes and an errata file.
- Problem Set 1, clearly marked as an archived assignment with no solutions.

The material has been tested for factual retrieval, mathematical tutoring, source boundaries, and figure interpretation in GitHub Copilot Spaces.
